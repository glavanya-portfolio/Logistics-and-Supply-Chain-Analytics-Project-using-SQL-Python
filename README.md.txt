# Logistics & Supply Chain Analytics Project

This project was developed using Python and MySQL.

Features:
- Generated synthetic logistics datasets
- Designed relational database
- Performed data validation
- Conducted business analysis
- Implemented Joins, CTEs, Window Functions
- Created Views and Stored Procedures
- Applied Indexes for query optimization

Tools Used:
- Python
- Pandas
- NumPy
- MySQL
- MySQL Workbench
- GitHub
