# Logistics and Supply Chain Analytics Project

## Project Overview
This project demonstrates an end-to-end Logistics and Supply Chain Analytics solution using Python and MySQL.

## Objectives
- Generate realistic logistics datasets using Python
- Design and implement a relational database in MySQL
- Perform data validation and cleaning
- Analyze shipment performance and delivery efficiency
- Identify high-value customers and business trends
- Optimize warehouse and route utilization

## Dataset
The project contains:
- Customers
- Orders
- Warehouses
- Vehicles
- Drivers
- Routes
- Shipments

Total Records:
- Customers: 500
- Orders: 5000
- Shipments: 5000
